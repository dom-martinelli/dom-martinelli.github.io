# Working on this site

Static site. `build.py` reads the JSON cards in `content/` and writes
`index.html`, `gallery.html` and `projects/*.html`. Those HTML files are build
output: never edit them by hand, the next build overwrites you.

```bash
python3 build.py          # after ANY change under content/
```

## Where the card order lives

`ORDER.md` at the repo root is the homepage order, regenerated by every build.
**Read it before answering any question about what is where.** If it disagrees
with the page, the build has not run.

Order inside a shelf comes from `featured` in `content/<slug>.json`: lower
number first, then cards that have figures, then everything else. To move a
card, change its `featured` number and rebuild. That is the whole mechanism.

There is one shelf for projects, not a "tools" shelf and an "analyses" shelf.
Dominic asked for that division removed three times before it went; do not
reintroduce it.

## Card fields

`slug` `tab` `title` `status` `public` `featured` `paper_only` `line`
`question` `did` `found` `so_what` `calls` `broke` `tried` `not_shown`
`figures` `acknowledgement`

`figures` is a list, so a card can carry as many as it needs.
`public: false` keeps a card off the homepage and deletes its project page on
the next build.

Some datasets require an acknowledgement on any page built from them. The AD
Knowledge Portal cards (`treated-disease`, `emory-vascular`) carry one in the
`acknowledgement` field. Do not drop it.

## Figures

House style lives in `figstyle.py` in the `patient-innovation-index` repo.
Saturated hues `#3D7BB8 #C4545C #00918A #B87C14 #7B62A8`, the shared `DIV` ramp
for heatmaps, 11pt type floor, portrait by default so it survives a phone.

**No title and no caption inside the PNG.** A figure is a figure: axes, marks,
legend, units. The headline and the explanation go in the card's `figures[].note`
and in the body text, never baked into the image. Baking them in means the figure
cannot be reused in a slide, a manuscript or a poster without being regenerated,
and it makes a thumbnail unreadable because the type is sized for a full-width
page. Dominic asked for this on 26 Nov 2026.

So: write the figure script to emit a bare image, and print the title and caption
to stdout so they can be pasted into the card instead.

Render every figure and look at it before committing. Matplotlib will happily
overlap a title with an axis label and report no error.

To put a figure in the all-figures gallery, add a row to `FIGURES` in
`scripts/sync_gallery.py`, then run that script and rebuild.
