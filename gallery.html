how this stays current

Each file sits in gallery/ under a fixed name. Rerun the figure scripts, run scripts/sync_gallery.py, and every figure here is overwritten in place, so the page never drifts from what the code produces. Palette and marks come from figstyle.py, version 2026-09-21 pastel-classes: pastel fills, strokes derived in CIELAB, transparency set by how crowded each point is.
