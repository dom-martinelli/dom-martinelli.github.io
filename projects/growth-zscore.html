Height z-score computation by language models

Whether a child gets referred for a short-stature workup can hinge on one calculated number. This project tests whether AI models can compute that number correctly, and where their math breaks down.

Code on GitHub

The question

Can large language models correctly compute a child's height-for-age z-score from the CDC growth reference, and land on the right side of the referral threshold?

Why it matters

A height z-score below -2 is the standard trigger for evaluating a child for conditions such as growth hormone deficiency, Turner syndrome, or hypothyroidism. A model that is only slightly off near that line can turn a referral into a missed diagnosis, which a typical average-error metric would treat as a near miss. If language models are going to help interpret growth, their errors need to be measured in clinical terms.

What I did

  • Built a command-line tool that sends a child's age, sex, and height to a chosen model and compares its answer to ground truth computed from the public CDC 2000 reference table using the LMS method.
  • Scored each answer on whether the model and the ground truth agree about which side of the -2 threshold the child falls on (the clinically safe rate), not only on numeric error.
  • Designed three conditions that isolate failure modes: closed book, formula provided, and formula plus the reference parameters provided, so errors can be traced to formula recall, table lookup, or arithmetic.
  • Tagged cases by difficulty, including exact table ages, ages between table rows, cases near the threshold, extreme values, and the switch between WHO and CDC references.
  • Supported several model families through one OpenRouter key, with offline tests that run without an API key.

What I found

  • Across the models reported, giving the model the reference parameters helped more than giving it the formula, so the main failure is recalling the reference values rather than knowing the equation.
  • Numeric error alone misses the clinically important mistakes, which cluster where a small miss changes the referral decision.

Limits

  • Pre-publication work: per-model results are not shown here.
  • Covers stature-for-age only, not weight or BMI charts.
  • This repository is the single-case and small-batch runner; the full benchmark lives separately.
