Benchmark item monitor

Medical AI models are scored on published multiple-choice benchmarks. This re-reads those benchmarks where they actually live, on Hugging Face, and counts the items that are broken as printed: text with letters missing, the same answer offered twice, a key naming an option that was never offered.

Every check is mechanical. Same rows in, same answer out, no model and no judgement, so anyone can re-derive any number here from the same rows.
